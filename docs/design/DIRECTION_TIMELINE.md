## What changed at the ecosystem pivot

- Core destination: artwork/scrapbook → evolving cyber-nature tree.
- Daily record: colour history retained; leaf clusters add an ecosystem representation.
- Emotional interpretation: earlier sentiment-to-colour idea expands to temporal patterns and symbolic visitors; no algorithm approved.
- New creature candidates: ladybug/happy-go-lucky, butterfly/sadness, rabbit/turmoil, hedgehog/uncertainty.
- New material candidate: dark obsidian-like glass trunk and branches.
- Future ideation: richer thoughts input and the full cyber treatment.
