# Screen One — Daily Contribution

Updated: 2026-10-03. Current direction: colour-first entry within a seasonal ecosystem.

## Retained requirements

- Colour selector, compact contribution history, and an input for thoughts and feelings.
- Selector candidates: rim wheel, 2D colour field, two-colour gradient; compare separately.
- A recorded colour updates its date in history and supplies one leaf cluster on the tree.
- History remains separate from selection. Saved colours are not emotional intensity scores.
- Neutral missing days; no streaks, scores, or punitive completion language.

## Open behaviour

The user's intended loop is colour choice → history contribution. Whether selection commits immediately or requires a save boundary is unresolved. Draft movement must not silently become multiple contributions. Editing, deletion, date/timezone handling, and the tree's corresponding update require specification.

Thoughts input remains part of the direction. Its richer interaction is deferred for later ideation; do not invent a replacement. Existing placeholder “A thought, a fragment, a detail…” remains available pending revision. No new prompt is approved.

The minimal white notebook, red margin, and prior diary composition are historical styling, not mandatory ecosystem requirements. No new typography or navigation is selected by this update.
